# Sohedra

Svelte for the web and for native apps.

- **UI components:** headless, accessible components for Svelte and SvelteKit.
- **Router:** a typed router for client-side Svelte apps.
- **Native apps:** a framework for iOS and Android apps in Svelte, rendering real native views
  through [Lynx](https://lynxjs.org).

The components and the router keep one API on the web and in native apps. Everything lives in
[sohedra/sohedra](https://github.com/sohedra/sohedra).

> **Status: early development.** Nothing is published yet.
